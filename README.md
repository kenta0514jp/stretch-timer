# 大腿四頭筋ストレッチ タイマー

左右30秒×2〜3セットのストレッチ用インターバルタイマー。**音と色で左右の切り替えを知らせる**ので、ストレッチ中に画面を見続ける必要がありません。

👉 **[使う](https://kenta0514jp.github.io/stretch-timer/)**

## なぜ作ったか

下り坂のあとの大腿四頭筋ストレッチは「左右30秒 × 2〜3回ずつ」。片手を壁につき、もう片方の手で足首を持っている状態では、スマホを操作できないし画面もよく見えない。だから **置いたまま使えること** を最優先にした。

## 動作

```
準備5秒 → 右30秒 → 入れ替え5秒 → 左30秒   ← これで1セット
                                    ↓
                        セット間も入れ替えの5秒だけ
```

- **右＝オレンジ / 左＝ティール** — 画面全体の色が変わるので、ちらっと見るだけで判別できる
- 開始と切り替わりで **チャイム**（ソ→ドの「ピ・ポーン」）。スマホなら振動も
- **残り5秒からカウント音** — 時報と同じで、同じ高さのピッを5回。切り替わりの瞬間に1オクターブ上の音が鳴って区切りになる
- 実行中は **画面が消えない**（Screen Wake Lock）
- 片側の秒数（20/30/45秒）、セット数（2/3回）、音のオン/オフを変更可能。設定は次回も保持

## 音が鳴らないとき

設定の **「音を確認」** を押すと、チャイムが鳴ると同時に今の状態が表示される。ここで原因の切り分けができる。

- **iPhone の消音（マナーモード）スイッチ** — いちばん多い原因。iOS Safari はこのスイッチで Web Audio の音まで止める。iOS 16.4 以降は Audio Session API で `playback` を宣言しているので鳴るはずだが、古い iOS ではスイッチを解除する
- **音量が着信音量になっている** — iPhone は再生中に音量ボタンを押すとメディア音量が変わる。無音のときに押しても着信音量しか動かないので、いちど「音を確認」を押してから音量を上げる
- **ブラウザが音をブロックしている** — 画面のどこかを一度タップすれば解除される。「ブラウザが音を止めています」と表示されたらこれ

## 使い方のメモ

ふくらはぎストレッチなど、ほかの左右ストレッチにも使える。片側だけ長くしたいときは、そのターンで一時停止して延ばす。

## 技術

依存ライブラリなし。HTML 1枚と、ホーム画面用のアイコン画像1枚だけ。

- 音は Web Audio API（`OscillatorNode`）で生成。倍音は**厳密な整数倍**（2倍・3倍）に限る。非整数倍にすると鐘のようになり、音程がぼやける
- 音階はCメジャーのみ（ド・ミ・ソ・ド）。半音を使わない
- エンベロープは「6msで立ち上げ → 音量を保つ → 減衰」。保つ区間が音の芯になる。コンプレッサーは通さない（立ち上がりが潰れるため）
- `navigator.audioSession.type = 'playback'` と無音 `<audio>` の再生で、iOS の消音スイッチ対策
- 秒の刻みは `Date.now()` 基準で補正（`setInterval` のずれと、バックグラウンドでの間引きの両方に対応）
- 振動は `navigator.vibrate`
- 画面の常時点灯は `navigator.wakeLock`
- 設定の保持は `localStorage`
- ライト/ダークの両テーマに対応（`prefers-color-scheme` と明示指定の両方）
- `prefers-reduced-motion` を尊重
- アイコンはランジ姿勢のピクトグラム。favicon はSVGをデータURIで直接埋め込み、ホーム画面用（`apple-touch-icon`）だけ iOS がSVGを受け付けないので180pxのPNGを置いている

いずれも未対応の環境では、その機能だけ静かに無効化されて本体は動く。
